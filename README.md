# 极趣墨水屏 · 基金盘中估值看板

一个专为极趣墨水屏 (Zectrix) 打造的自动化看板：在 A 股交易时段，自动抓取你关注的基金盘中涨跌幅估值并推送到墨水屏。完全免费，基于 GitHub Actions 运行，无需自建服务器。

---

## 📌 看板显示内容

本项目适配 400×300 分辨率墨水屏。屏幕顶部为标题栏（含刷新时间），下方逐只列出基金：每只一行大号涨跌幅（`▲` 涨 / `▼` 跌），下方小字标注估值/持仓覆盖率与行情时间。基金较多时自动分页推送。

支持两类基金：

- **直接估值基金**：有天天基金官方实时估值的基金，直接取官方估值涨跌幅。
- **持仓估算基金**：没有官方实时估值时，按基金披露的**前十大持仓** × 成分股实时涨跌幅估算（未披露持仓与仓位变化按 0 处理，仅供参考）。

单只基金数据源临时故障不会影响整体：该基金标注为「估算不可用」，其余照常显示。非交易日 / 收盘后不推送，墨水屏保留上一次画面。

## 🛠️ 部署指南

### 1. 复制项目 (Fork)
点击本页面右上角的 **`Fork`** 按钮，将本项目复制到你自己的 GitHub 账号下。

### 2. 上传中文字体文件（可选）
如需更换字体：准备一个中文 `.ttf` 字体，重命名为 **`font.ttf`**（全小写），在仓库首页 **`Add file`** → **`Upload files`** 上传并覆盖原文件。默认使用 `MiSans-Medium`。

### 3. 配置隐私密钥 (Secrets)
点击仓库 **`Settings`** → **`Secrets and variables`** → **`Actions`** → **`New repository secret`**，添加以下 2 个密钥：

| 填在 Name 里 | 填在 Secret 里 | 获取方式 |
|---|---|---|
| `ZECTRIX_API_KEY` | 你的极趣云 API Key | 登录 [极趣云控制台](https://cloud.zectrix.com) 获取 |
| `ZECTRIX_MAC` | 墨水屏 MAC 地址 | 格式如 `AA:BB:CC:DD:EE:FF` |

### 4. 配置你的基金
打开 **`main.py`**，点击 ✏️ 编辑，在顶部**用户自定义区**修改：

- `FUND_DIRECT`：直接估值基金代码，逗号分隔，如 `"160419,003015"`。名称自动获取。
- `FUND_ESTIMATED`：持仓估算基金，格式 `代码:名称`，多只用逗号分隔，如 `"007355:汇添富科技创新混合A"`。
- `PANEL_TITLE`：屏幕顶部标题。

> 不确定某只基金属于哪一类？先填进 `FUND_DIRECT`，若显示「估算不可用」，再挪到 `FUND_ESTIMATED`。

### 5. 修改推送时段（可选）
默认在 **A 股交易时段**（北京时间周一至周五 9:30–15:30）每小时推送一次。如需修改，编辑 `.github/workflows/run.yml` 中的：

```yaml
cron: '30 1-7 * * 1-5'
```

**注意：此处使用 UTC 时间，比北京时间慢 8 小时**（北京 9:30 = UTC 1:30）。

### 6. 手动运行并激活
点击仓库顶部 **`Actions`** 选项卡 → 若有绿色提示则点击启用 → 在左侧选中推送任务 → 点击 **`Run workflow`** 手动运行一次。

## 🧪 本地调试

在本地渲染检查版式（不推送、不需要密钥）：

```bash
pip install requests pillow
DRY_RUN=1 python main.py     # 交易时段会生成 page_1.png 等，用图片查看器打开检查
```

也可单独运行数据脚本查看文本结果：

```bash
python fund_alert.py --direct 160419,003015 --estimated 007355:汇添富科技创新混合A
```
